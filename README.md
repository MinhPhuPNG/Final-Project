Name:
3x20

To Launch: Simply press play in unity either from MainMenu scene.

Concept:
First Person simple story game where you follow the objectives listed, with a start scene to introduce NPC's visual novel dialogues. Gameplay includes collecting ingredients to brew potions and a 2D spelltracing minigame at the end. 

Controls:
Basic WASD and Mouse movements, Left Mouse button to Jump, with interactions by pressing E and F. Shift to Run. 

Objective: Complete the game by following the Objective Text to speak to all required NPC's and finally complete the game.



Checkpoint 1:
Functionality - Resource collection script for future implementations of resources, first person controls, basic dialogue prompt interaction.
Character can move, start and cycle through a dialogue with the NPC, and 3 resources can be kept track of currently. Future plans are to implement a recipe based potion game with new resource assets, replacing current resources.

Checkpoint 2:
Functionality - Added completed skeleton of maps needed for daytime, night, functional writing/tracing minigame, and interactions with doors, cauldrons, and resources/collectables. Placeholder npc models currently occupy all NPC's for needed dialogue/story progression along with a basic hazard.
Future plans are to add actual models for different npc's and a 2D art/sprite, cleanup UI for places that are left clunky such as the map being unclean/glitchy due to prefab overlaps and dialogue being one sided one time popups rather then any back and forth. If there's time I will implement an actual ending rather then simply cutting to a 2D ending screen.
